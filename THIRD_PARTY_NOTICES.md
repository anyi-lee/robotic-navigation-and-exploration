# Third-party and course-provided components

This portfolio repository contains selected student implementations created within the *Robotic Navigation and Exploration* course. The surrounding simulators, assignment scaffolding, and robot platform were provided by the course or their respective upstream projects.

## Final-project framework

- PROS car framework: <https://github.com/asd56585452/pros_car>
- PROS application environment: <https://github.com/asd56585452/pros_app>
- ROS 2, Nav2, AMCL, Foxglove, OpenCV, Ultralytics YOLO, and PyTorch retain their original licenses and attribution requirements.

The submitted final-project snapshot was compared with `pros_car` commit `3659e6395a9644cd0c82cc784d9f3b82de788275`. Five framework files contained project-specific modifications:

- `mode_manager.py`
- `nav_processing.py`
- `arm_controller_2D.py`
- `ros_communicator.py`
- `data_processor.py`

The portfolio includes these modified files for review and does not redistribute the complete upstream repositories.

## Coursework folders

The HW1–HW3 code files depend on course-provided scaffolding that is not reproduced in full. HW4 model weights and result media were produced from a student-collected and student-labeled dataset in the PROS Twin environment.
